这个定制器是什么？

网站的所有内容（文字、图片、颜色）都放在 content/ 文件夹里，代码不需要动。这个页面就是 content/ 的图形化编辑器：你在左边改，右边立即看到效果。

定制器只在本地开发时可用，不会被发布到线上网站。

推荐的定制顺序

1. 基本信息：填写联系方式、上传头像和二维码
2. 首页内容：填写名字、标题、签名和时间线（中英文都填）
3. 外观风格：挑选风格包并按需微调
4. 项目作品：替换示例项目或新建自己的项目
5. 检查并导出：下载独立网站 ZIP，再上传到托管平台

想改这里没有的内容？

用 Claude Code 打开这个项目文件夹，直接说你想要什么，例如：
"简历页换成我的简历"
"侧边栏底部的数据指标改成……"
"把技能矩阵里的工具换成我常用的"

项目里已内置定制技能（.claude/skills/customize-site），Claude 知道每个内容对应哪个文件。

改坏了 / 想重新开始

顶部的 撤销本次修改 可以恢复到本次打开定制器之前的状态。

想重新开始，可以把整站恢复为中性示例内容，当前内容会先自动备份。

重置前会自动备份当前内容到 .studio-snapshots/ 文件夹，不会真的丢失。

怎么发布上线

内容改好后，点击顶部的“检查并导出网站”。下载的 ZIP 只包含最终静态网站，不包含 Studio、模板源码或 content/。解压后可以上传到 Netlify、Cloudflare Pages 或 Vercel。以后要修改，请回到 Studio 再次导出。

可选页脚署名

显示页脚署名 默认关闭。开启后，页脚会显示你在 content/config/site.yml 中设置的署名文字和链接。
