这个定制器是什么？

          
网站的所有内容（文字、图片、颜色）都放在 content/ 文件夹里，代码不需要动。这个页面就是 content/ 的图形化编辑器：你在左边改，右边立即看到效果。

          
定制器只在本地开发时可用，不会被发布到线上网站。

        

        

          
推荐的定制顺序

          
1️⃣ 基本信息：改名字、传头像和二维码

             2️⃣ 首页文案：改标题、签名、技能标签（中英文都填）

             3️⃣ 外观配色：挑个主题色、调圆角

             4️⃣ 项目作品：把示例项目改成你自己的，或新建

             5️⃣ 博客文章：不需要可以不管，卡片会自动隐藏空内容

        

        

          
想改这里没有的内容？

          
用 Claude Code 打开这个项目文件夹，直接说你想要什么，例如：

            "把时间线改成我的经历：2020 年……"

            "简历页换成我的简历"

            "把 Personal AI 卡片去掉"

          
项目里已内置定制技能（.claude/skills/customize-site），Claude 知道每个内容对应哪个文件。

        

        

          
发布上线

          
定制完成后运行 npm run build，把 dist/ 部署到 Cloudflare Pages / Vercel / Netlify 等任意静态托管即可。详细步骤见 docs/CUSTOMIZE.md。
