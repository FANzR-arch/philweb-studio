这个定制器是什么？

          
网站的所有内容（文字、图片、颜色）都放在 content/ 文件夹里，代码不需要动。这个页面就是 content/ 的图形化编辑器：你在左边改，右边立即看到效果。

          
定制器只在本地开发时可用，不会被发布到线上网站。

        

        

          
推荐的定制顺序

          
1. 基本信息：改名字、传头像和二维码

             2. 首页内容：改标题、签名、时间线（中英文都填）

             3. 外观风格：挑个风格包、调圆角

             4. 项目作品：把示例项目改成你自己的

             5. 发布上线：体检 → 打包 → 拖拽上传

        

        

          
想改这里没有的内容？

          
用 Claude Code 打开这个项目文件夹，直接说你想要什么，例如：

            "简历页换成我的简历"

            "侧边栏底部的数据指标改成……"

            "把技能矩阵里的工具换成我常用的"

          
项目里已内置定制技能（.claude/skills/customize-site），Claude 知道每个内容对应哪个文件。
