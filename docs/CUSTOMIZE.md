# 🚀 三步把这个网站变成你自己的（小白版）

不需要懂代码。你只要会：打字、选图片、点按钮。

---

## 第 0 步：装环境（只做一次）

1. 安装 [Node.js](https://nodejs.org/zh-cn)（LTS 版本，一路下一步）。
2. 下载本项目文件夹，在文件夹里打开终端（Windows：地址栏输入 `cmd` 回车；Mac：右键 → 新建位于文件夹位置的终端窗口）。
3. 输入：

```bash
npm install
```

等它跑完（第一次要几分钟）。

## 第 1 步：打开可视化定制器

```bash
npm run studio
```

浏览器会自动打开 `http://localhost:3000/studio`：**左边是表单，右边是你的网站实时预览**。改什么立刻能看到什么。

**两个最好用的功能：**

- **点哪改哪**：直接在右侧预览里点击你想改的文字或图片（比如点一下名字、点一下头像），左边会自动跳到对应的编辑框。不用找。
- **定制进度条**：顶部的进度清单告诉你还剩什么没改，点任意一项直接跳过去。全绿就可以发布了。

各标签页：

| 标签页 | 能做什么 |
|---|---|
| 👤 基本信息 | 改名字、微信号、社交链接；上传头像和微信二维码 |
| 📝 首页文案 | 改首屏标题、个人签名、技能标签、板块标题（中英文） |
| 🎨 外观配色 | 6 套整套风格包（含字体）一键实时预览；微调主题色、圆角、背景光晕、页面疏密 |
| 📦 项目作品 | 修改示例项目为你自己的项目、上传封面和截图、新建/下架项目 |
| ✍️ 博客文章 | 新建文章卡片（标题+摘要+链接+封面），不需要博客就都下掉 |
| 🚀 发布上线 | 一键体检 → 一键打包 → 按图文引导拖拽上传，全程不需要懂 Git |

> 改坏了不用慌：顶部有"↩ 撤销本次修改"；帮助页还有"重置为示例内容"可以整站重来。定制器只在你自己电脑上运行，不会发布到线上。

## 第 2 步：想改更多？直接跟 Claude 说

定制器覆盖不到的内容（时间线经历、简历、项目案例长文、技能矩阵……），用 [Claude Code](https://claude.com/claude-code) 打开这个文件夹，用大白话说需求即可，例如：

- "把时间线换成我的经历：2021 年大学毕业，2022 年……"
- "简历页换成这份"（然后把你的简历文字粘贴进去）
- "这是我的项目截图，帮我加到 xx 项目里"（直接发图片）
- "把整站换成蓝色系，圆角再大一点"

项目里内置了定制技能（`.claude/skills/customize-site/`），Claude 知道每样内容放在哪个文件、改完会自动帮你校验。

## 第 3 步：发布上线（定制器里点着走）

打开定制器的 **🚀 发布上线** 标签页：

1. **一键体检** — 自动检查内容是否完整合法
2. **一键打包** — 生成 `dist/` 文件夹（等 1~2 分钟）
3. **拖拽上传** — 跟着页面里的图文指引，把 dist 文件夹拖进 [Netlify Drop](https://app.netlify.com/drop) 或 Cloudflare Pages 直传页面，几十秒后拿到网址 🎉

想用 Git 自动部署（改完推送即更新）：把项目推到 GitHub，在 Vercel / Cloudflare Pages / Netlify 导入仓库，构建命令 `npm run build`，输出目录 `dist`。

> "Personal AI" 对话功能需要你自己的 Coze 机器人和密钥（见 README 的 Coze 章节）。不配置也没关系——线上会自动禁用，不影响其他部分。
>
> 页脚默认有一行"基于 folio-studio 开源模板搭建"的小字（支持模板作者 🙏）。想关掉：发布页最下方有开关。

## 常见问题

**Q：改坏了怎么办？**
定制器顶部有 **↩ 撤销本次修改**（恢复到本次打开前）；帮助页有 **重置为示例内容**（整站换回示例人设"林小满"，从零开始）。两者都会先自动备份到 `.studio-snapshots/`，不会真丢。命令行党也可以 `npm run content:reset -- --yes` 或 `git checkout -- content/`。

**Q：保存后预览没变化？**
点预览栏的 🔄 刷新；还不行就看终端有没有红色报错（通常会指出哪个文件哪一行有问题），或运行 `npm run content:check` 检查。

**Q：想手动改文件？**
可以，全部内容都在 `content/` 目录，结构说明见 `content/CONTENT_STRUCTURE.md`。改完跑 `npm run content:check` 校验。

**Q：图片有什么要求？**
定制器上传时会自动压缩。手动放图的话：头像建议 ≤640px、封面 ≤1600px 宽，格式用 JPG/PNG/WebP。
