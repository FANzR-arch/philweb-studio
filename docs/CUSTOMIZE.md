# 用 PhilWeb Studio 制作并发布个人网站

## 1. 打开编辑器

推荐直接打开在线版：<https://fanzr-arch.github.io/philweb-studio/>

不需要安装 Node。数据只保存在当前浏览器，换设备前请导出工程备份。

本地开发：

```bash
npm install
npm run studio
```

浏览器打开编辑器。左侧编辑，右侧预览。

## 2. 完成定制

推荐依次修改：

1. 基本信息：联系方式、头像、二维码和 Logo。
2. 首页内容：名字、首屏介绍、技能、经历、指标和快捷入口。
3. 简历、联系方式和技能。
4. 外观风格：选择风格包，必要时再打开高级微调。
5. 项目作品：修改项目文本、封面、详情图、链接和展示状态。
6. 博客文章：新建、修改或下架文章。

右侧预览支持“点哪改哪”。在线版改动写入当前浏览器，不会写入 GitHub 仓库。

## 3. 检查并导出

完成后点击“检查并导出网站”。导出会检查：

- 内容结构和中英文成对情况。
- 图片引用和资源预算。
- TypeScript 类型和生产构建。
- 示例姓名、假邮箱、社交账号和模板品牌是否残留。

检查通过后下载 ZIP。ZIP 是独立的静态网站，不包含 Studio、模板源码、`content/` 或 Node 配置。

## 4. 部署

解压 ZIP 后，可以把文件上传到 Netlify、Cloudflare Pages、Vercel 或其他静态托管服务。

如果使用命令行，也可以运行：

```bash
npm run export
```

命令行导出的文件位于 `exports/`。

## 5. 修改与恢复

导出后的 ZIP 不再参与编辑。要修改网站，请回到 PhilWeb Studio 项目，再次运行 `npm run studio`。

Studio 会在启动时保存内容快照。顶部“撤销本次修改”可以恢复本次会话开始前的内容，帮助页的“重置为示例内容”会先备份当前内容再恢复中性示例。
